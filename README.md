# Deadcord
A discord bot to show and look up deadlock stastics

## How to run?
To run the discord bot you need to have a working go setup, add a token into your ``.env`` file and run a go command.

1. The .env file:
```bash
TOKEN=YOUR_BOT_TOKEN
```

2. Run this go command:
```bash
go run src/main.go
```
